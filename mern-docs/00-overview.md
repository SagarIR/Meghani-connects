# Meghani Connect 360 (MERN) – Project Overview

## Project Information

| Field | Value |
|-------|-------|
| **Name** | Meghani Connect 360 |
| **Type** | Multilingual Web & Desktop Management System |
| **Client** | Meghani Watch Co. |
| **Purpose** | Sales, Repairs, Inventory, CRM, and AI Analytics with WhatsApp/SMS automation |

---

## Technology Stack

| Layer | Technology |
|-------|------------|
| Frontend | React.js + Vite + TailwindCSS |
| Backend | Node.js + Express.js |
| Database | MongoDB |
| Hosting | Local (Offline) + Cloud Sync (Online) |
| APIs | Twilio/WhatsApp, SMS Gateway, Razorpay |
| AI Libraries | TensorFlow.js, Brain.js, Simple-Statistics |

---

## Core Features

1. **Dashboard & Analytics** - Real-time sales/profit charts with AI insights
2. **Sales & POS System** - Barcode billing, thermal printing, multiple payment modes
3. **Repair Management** - Job tracking with auto reminders
4. **CRM Module** - Customer data, loyalty points, birthday offers
5. **AI Analytics Engine** - Sales forecasting, stock predictions
6. **Notifications** - WhatsApp/SMS automation
7. **Cloud Sync & Backup** - Offline-first with scheduled sync
